# Family Movie Watchlist API

API de listas de películas con autenticación JWT y permisos para padres e hijos.

Proyecto de certificación del curso Back-End Development and APIs de [freeCodeCamp](https://www.freecodecamp.org/learn/back-end-development-and-apis-v9/). Incluye el código del ejercicio y los archivos base del curso.

## Ejecutar

Requiere Node.js 24 o posterior y npm.

Antes de iniciar, copia `.env.example` a `.env` y sustituye `JWT_SECRET` por una clave aleatoria propia. Los usuarios de `data/users.json` son datos de ejemplo proporcionados por freeCodeCamp.

```bash
npm install
npm start
```

Servidor local: http://localhost:3000
